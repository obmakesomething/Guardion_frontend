케이스 상세 (O-03)

리스크 게이트

  • Proceed / Need approval / Reject → `POST /ops/cases/{id}/decision`
  • Need approval는 고객 UI에 이름/전화/이메일만 요청

배차/정산

  • DispatchPanel: 후보 기사 정렬 + 배정 버튼
  • 수락 시 3,000원 정산 이벤트 기록(배지/토스트/로그)

추가비 동의

  • 기사 요청 추가비를 고객 재동의 받았는지 확인/로그 노출
  • 동의 로그: 시각/금액/담당자/방식 + 이벤트 consumer_fee_consent

증빙/로그

EvidenceGallery(전/후 필수), AuditLog(누가/언제/무엇을) 확인.

전/후 사진 필수 요건을 검증하고, “기존 하자 미기록 시 책임 안내”를 표시합니다.

CS 운영

  • 취소/노쇼/지연 기준: 출동 시작 이후 취소 시 출동비 발생 등
  • 이의제기 접수 채널: 카톡/전화 + 폼(시간/주소/증빙) 링크 유지
  • 고객에게 중개자 고지, 기사 상호/연락처/사업자정보 노출 여부 확인
콜센터가 수기로라도 입력/확인할 수 있는 필드를 둡니다.

정책/법무

  • 중개자 고지 문구 상시 노출
  • 개인정보처리방침 `/legal/privacy` 링크(수집항목/목적/보유기간/제3자 제공/파기/문의처)
  • 추가비 재동의에 대한 SMS/서명 요청 기록 유지
