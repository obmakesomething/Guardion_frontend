MVP Wireframe

바로 실행

요청 시작과 진행 화면으로 이동하는 주요 CTA입니다.

지도는 영역+ETA만, 기사 번호는 직통 노출. Need approval 시 이름/전화/이메일만 수집합니다.

요금/동의

기본 출동비·기본 작업비·추가 작업비를 사전 고지하고 동의를 기록합니다.

항목금액설명
기본 출동비예: 30,000원출동 시작 후 취소 시 발생
기본 작업비예: 40,000원단순 개방/점검
추가 작업비현장 동의 필요실린더 교체 등 부품 비용 포함

현장 추가비 발생 시 재동의(버튼/서명/문자 확인)를 받아 시각/금액/담당자/방식을 로그로 남깁니다. 이벤트 예시: consumer_fee_consent.

요청 흐름

C-01 요청 작성

  • 위치 선택(MapAreaSelector), 상황 입력, 사진 업로드, 연락처(필수)
  • 기본 요금 고지 + 동의 체크, 정책 안내(지도 제한/직통 연락/취소 규칙)
  • 제출 후 SUBMITTED → C-02 이동

C-03 진행/트래킹

  • 영역+ETA 맵, 상태 타임라인, 기사 번호 노출 ContactBlock
  • 추가비 재동의 모달/CTA, EvidenceGallery, OTP/리포트 CTA
  • 404/401 시 InlineError로 재시도/로그인/지원 요청 안내

지도/연락·증빙

AreaEtaMap — 영역+ETA만, 정밀 점 숨김

ContactBlock: 기사 직통 번호 노출, “안전상 정확한 위치는 표시하지 않습니다.” 문구 포함.

전/후 사진 (필수)

  • 문/도어락/실린더 전·후 모두 업로드, 기존 하자 미기록 시 책임 안내
  • 콜센터/고객 리포트에서 확인 가능

정책/고지

  • 중개자 고지: “본 플랫폼은 통신판매 당사자가 아닌 중개자” 문구 노출
  • 취소/노쇼/지연 기준 안내(출동 시작 후 취소 시 출동비 등)
  • 이의제기 접수 채널: 카톡/전화 + 폼(시간/주소/증빙)
  • 개인정보처리방침 링크: 수집항목/목적/보유기간/제3자 제공/파기/문의처
푸터나 리포트/문자에 고지 및 링크를 노출합니다.
